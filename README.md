### コントローラー配置

- 左手で操作する左右ボタン（← →）を画面左に置く。
- 右手で操作する上下ボタン（↑ ↓）を画面右に置く。
- 画面下部のおよそ1/5を操作領域にし、中央を境に左右へ半分ずつ割り当てる。
- 左側の領域は左右2分割して←／→、右側の領域は上下2分割して↑／↓として反応させる。矢印を大きく表示し、各領域全体を押せるようにする。
- この左右分離の配置は維持する。中央にまとめたり、方向キーを十字配置に変更したりしない。
- [x] 左右分離の大きなタッチ領域を実装（動作確認待ち）

## 起動方法

`prototype/index.html` をブラウザで開きます。現時点ではビルド手順や外部ライブラリはありません。

## 実装メモ

- 画面・入力・描画処理は `prototype/index.html` にまとまっています。
- モバイルのタッチ操作とデスクトップのキーボード操作を想定しています。
- 描画位置はパッドまたはキーでのみ移動できます。キャンバスのタップでは移動しません。
- タイトル表示は置かず、ネオン・色・クリアの操作ボタンを左上に配置しています。
- ヘッダー右端のダウンロードアイコンから、操作UIや位置マーカーを除いた描画範囲をPNG保存できます。
- 色ボタンの右に線幅アイコンがあり、細線（1.2px）と太線（2.4px）を切り替えます。初期状態は細線です。
- 線幅アイコンの右に速度計アイコンがあり、遅い速度（0.6px/frame）と速い速度（1.25px/frame）を切り替えます。初期状態は遅い速度です。
- Etch A Sketch風テーマは取り下げ済みです。画面は従来の暗いスタイルで表示します。
- タッチ領域の方向表示は、向きごとに回転するインラインSVGの三角形です。
- 位置表示は描画範囲の外側に四辺の細い赤いSVGマーカーを出し、先端を中央へ向けます。四辺とも先端と描画境界の間隔を揃え、現在位置に合わせて移動させます。描画点では小さな白い点と、約2秒周期で広がって消える輪を表示します。
- 実装済みの改善項目は、ユーザーの動作確認後に完了扱いへ更新します。
